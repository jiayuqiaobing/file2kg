# Contract: MCP Tools

**Feature**: `001-serve-api-mcp` | **Date**: 2026-10-04 | **Spec**: [../spec.md](../spec.md)

MCP 入口由**同一个常驻服务**承载（与 HTTP 共用进程与模型实例，见 spec Assumptions），
因此 Agent 通过 MCP 调用同样享受模型常驻。

---

## 1. 工具清单

| 工具名 | 类别 | 注册条件 |
|--------|------|----------|
| `service_info` | read | **恒有** |
| `search` | read | **恒有** |
| `ingest` | write | **仅 `mode=read-write`** |

**默认模式下 `ingest` MUST NOT 被注册**——不是"注册了但调用报错"，是它**不在工具清单里**。
客户端（Agent）根本看不到它，因此不存在"Agent 误写库"的可能性。

> 这是 FR-008 / US2 场景 4 的落点，也是宪法原则 III 在 MCP 侧的全部意义：
> **权限不是运行时检查，而是注册期就不存在。**

---

## 2. `service_info` —— 只读

**用途描述**（Agent 据此判断要不要调用，FR-017）：

> 查询当前知识库服务的自述信息：所服务的库、绑定的嵌入模型与维度、权限模式（只读/可写）、
> 模型是否已加载常驻。不触发模型加载，可随时安全调用。

**参数**：无

**返回**：与 HTTP `GET /info` 同一结构（`ServiceDescriptor`）。

---

## 3. `search` —— 只读

**用途描述**：

> 在本地知识库中检索相关文档片段。返回带来源文件、标题层级与页码的片段，可直接用于引用。
> 使用混合检索（向量 + 关键词），对术语精确匹配（端口号、接口名）同样有效。

**参数**

| 名称 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `query` | string | 是 | — | 检索文本 |
| `k` | integer | 否 | 10 | 返回条数，1..50 |
| `hybrid` | boolean | 否 | `true` | 混合检索；`false` 为纯向量 |

**返回**：`SearchHit` 列表（**不含向量**，见 [data-model.md §2.3](../data-model.md)）。

每条命中带 `source` / `heading` / `page`，Agent 可据此给出可核对的出处。

---

## 4. `ingest` —— 写（仅 `read-write`）

**用途描述**：

> 对指定文档目录执行一次**增量**摄取：只处理新增与变化的文件，自动清理已删除文件对应的
> 旧内容。每次调用产生一份作业审计。耗时取决于变更量，可能较长。

**参数**

| 名称 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `docs_dir` | string | 否 | 服务启动时的默认目录 | 待摄取目录 |
| `force` | boolean | 否 | `false` | 忽略增量状态，全量重挂 |

**返回**：`JobSummary`（含 `audit_path`、`skipped_files`、`errors`）。

---

## 5. 工具清单的两种查看方式

| 入口 | 用途 | 只读模式下的结果 |
|------|------|------------------|
| MCP 客户端工具列表 | Agent 看到的清单 | 只有 `service_info`、`search` |
| HTTP `GET /info` → `capabilities` | 程序化检查 | `["service_info", "search"]` |

两者 MUST 恒等——**同一个 `CapabilityManifest` 驱动**，不允许各自维护一份清单。
测试 MUST 同时断言两处（见 quickstart 的验证场景 3）。

---

## 6. 不做的事

- **不注册资源（resources）/ 提示（prompts）**：本功能只需要工具。YAGNI，且减少暴露面
- **不提供写工具的"备用禁用版本"**：只读模式下写工具完全不存在
- **不通过工具参数切换权限**：权限模式在启动时固定，运行期不可变
  （这是"默认不存在"可被静态证明的前提，见 data-model.md §2.2）
